# منابع متن فارسی پلن‌اکت

<span dir="ltr">`app_fa.arb`</span> تنها فهرست قابل ویرایش متن فارسی متعلق به برنامه است. فارسی تنها زبان فعال و پیش‌فرض است؛ استخراج منابع، زبان جدید یا تغییر راست‌به‌چپ، تقویم، تکرار، پول و دادهٔ ذخیره‌شده ایجاد نمی‌کند.

## ویرایش متن

- کلید معنایی پایدار با قالب <span dir="ltr">camelCase</span> انتخاب کنید. اقدام مشترک از <span dir="ltr">`common…`</span> استفاده می‌کند؛ جابه‌جایی ویجت دلیل تغییر کلید نیست.
- توضیح <span dir="ltr">`@key.description`</span> را حفظ کنید. محل منبعِ متن منتقل‌شده مربوط به مبنای انتقال است، نه شمارهٔ خط فعلی.
- جمله یا قالب کامل را ترجمه کنید. پارامتر جایگزین و قرارداد آن حفظ شود؛ ترتیب <span dir="ltr">`value1`</span> و <span dir="ltr">`value2`</span> بخشی از امضای متد است. برای موارد جدید نام توصیفی بهتر است.
- پارامتر جایگزین مبلغ، عدد و تاریخ موجود، رشتهٔ قالب‌بندی‌شده از قبل است. مبلغ صحیح ذخیره‌شده را تغییر واحد ندهید یا با عدد اعشاری محاسبه نکنید. انتخاب جمع <span dir="ltr">ICU</span> به شمار صحیح جداگانه و مقدار نمایشی مناسب نیاز دارد؛ شمار را از متن فارسی حدس نزنید.
- خروجی <span dir="ltr">Dart</span> را دستی ویرایش نکنید. از ریشه اجرا کنید:

<div dir="ltr">

```sh
flutter gen-l10n
dart run tool/generate_persian_copy.dart
dart run tool/generate_persian_copy.dart --check
```

</div>

دریافت وابستگی یا ساخت <span dir="ltr">Flutter</span> منابع <span dir="ltr">`generated/app_localizations…`</span> را تولید می‌کند؛ بررسی مشترک، تولید منابع <span dir="ltr">Flutter</span> و خروجی مستقل <span dir="ltr">Dart</span> را هم کنترل می‌کند. تست مبنا قالب فارسی پیش از انتقال را ثابت نگه می‌دارد؛ تغییر عمدی به بازبینی و به‌روزرسانی مبنای مرتبط نیاز دارد.

## مرزهای مصرف

متن کنترل‌های اعلان بومی آلارم نیز از همان <span dir="ltr">ARB</span>، با فرادادهٔ
<span dir="ltr">`x-planact-android-resource`</span>، به <span dir="ltr">`planact_alarm_strings.xml`</span> تولید می‌شود.
فرمان تولید و <span dir="ltr">`--check`</span> بالا هر دو خروجی <span dir="ltr">Dart</span> و <span dir="ltr">Android</span> را بررسی می‌کنند؛
فایل <span dir="ltr">XML</span> تولیدی منبع قابل ویرایش جداگانه نیست.

ویجت از <span dir="ltr">`planActL10n(context)`</span> استفاده می‌کند و ریشه <span dir="ltr">`AppLocalizations`</span> را کنار منابع <span dir="ltr">Material/Cupertino</span> ثبت می‌کند. جایگزین ثابت فارسی برای تست منفرد و تعبیهٔ موجود است؛ زبان سراسری قابل تغییر ایجاد نمی‌کند.

متن دارای <span dir="ltr">`x-planact-default`</span>، کلاس <span dir="ltr">`PersianCopy`</span> در <span dir="ltr">`core/localization/persian_copy.g.dart`</span> را تولید می‌کند. همراه فقط ثابت و تابع قالب <span dir="ltr">Dart</span> دارد و به <span dir="ltr">Flutter</span>، پایگاه داده یا پلتفرم وابسته نیست. منبع قابل ویرایش دوم وجود ندارد؛ امضا و رفتار ثابت اعتبارسنجی دامنه، محاسبات کاربرد، نام تقویم و پیام آداپتور حفظ می‌شود. همراه مستقل فارغ از زبان ویجت فارسی می‌ماند؛ این مرز سازگاری است، نه آمادگی چندزبانه.

فعال‌سازی زبان دیگر به <span dir="ltr">ARB</span>، ورودی یا نگاشت نمایشی صریح برای خطا، محاسبه، توابع بدون بافت و پیام بومی، و آزمون مسیر واقعی نیاز دارد. زبان، تقویم تکرار، قالب عدد و واحد پول مستقل‌اند؛ ترجمه نباید تاریخ، یادداشت، دسته، دفتر مالی، ارتباط یا اعتبار را بازنویسی کند.
