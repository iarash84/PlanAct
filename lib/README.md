# ساختار برنامه

ساختار قابلیت‌محور و لایه‌ای مخزن:

- <span dir="ltr">`core/`</span>: انواع پایهٔ دامنه، زیرساخت مشترک و قراردادهای عمومی.
- <span dir="ltr">`features/`</span>: کد دامنه، کاربرد، داده و نمایش هر قابلیت.
- <span dir="ltr">`app/`</span>: ترکیب وابستگی‌ها و اتصال مسیرهای برنامه.
- <span dir="ltr">`l10n/`</span>: متن فارسی و خروجی تولیدشده؛ [راهنمای ویرایش](l10n/README.md).

وابستگی از نمایش به کاربرد و سپس دامنه است. داده و زیرساخت به قراردادهای دامنه/کاربرد وابسته‌اند؛ دامنه به <span dir="ltr">Flutter</span>، <span dir="ltr">Drift</span> یا <span dir="ltr">API</span> پلتفرم وابسته نمی‌شود. ویجت نباید جدول پایگاه داده را مستقیماً تغییر دهد.

مسیر تولیدی از مخزن‌های <span dir="ltr">Drift</span> استفاده می‌کند. مخزن حافظه‌ای برای تست، نمونه و پیش‌نمایش است، نه مرجع دادهٔ ماندگار. [قواعد معماری](../docs/ARCHITECTURE_AND_DOMAIN_RULES.md) و [قرارداد عامل](../AGENTS.md)
