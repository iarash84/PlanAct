# نقشهٔ توسعهٔ مرحله‌ای

این سند ترتیب مفهومی مراحل را نگه می‌دارد، نه فهرست پرامپت قابل اجرا یا اعلام تکمیل قابلیت‌ها. ارجاع P00 تا P38 به پوشهٔ ناموجود `prompts/` حذف شده است. وضعیت واقعی از [PRD](product/PRD.md) و گزارش پذیرش همان قابلیت خوانده می‌شود.

## روش کار

دامنهٔ محدود، مسیر واقعی، قرارداد پذیرش و تست مرتبط را پیش از تغییر تعیین کنید. هر تغییر مستقل، بازبینی و ثبت جدا داشته باشد؛ مهاجرت و تست آن همراه همان تغییر باشند. تصمیم معماریِ تازه در ADR ثبت شود. [گردش توسعه](development-workflow.md) مرجع اجرای جاری و [AGENTS](../AGENTS.md) قرارداد عامل است.

| مرحله | هدف | مرز پذیرش |
| --- | --- | --- |
| M0 | زیرساخت، SQLite/Drift، انواع پایه و تست | ساخت، تحلیل و بررسی ماندگاری؛ [شاهد تاریخی](M0_BASELINE.md) وضعیت امروز نیست. |
| M1 | تعهد، چرخه و چرخهٔ وضعیت | ذخیرهٔ مستقل از رابط و حفظ تاریخچه. |
| M2 | زمان‌بندی و تولید رخداد | تکرار قطعی، نسخه‌بندی، افق محدود و حفظ گذشته. |
| M3 | اعتبار جلسه و سیاست استثنا | محاسبه از دفتر اعتبار؛ بدون شمارندهٔ مستقل یا استثنای رابط. |
| M4 | قواعد و نمونهٔ یادآور | قصد پایدار و تحویل جدا؛ پذیرش دستگاه مستقل. |
| M5 | امروز، تقویم و ثبت ساختاریافته | مسیر کاربر متصل به فرمان کاربرد و دادهٔ پایدار. |
| M6 | نتیجه، شاهد و تاریخچه | ثبت و بازگشایی قابل توضیح؛ مسیر کامل پیوست هنوز باز است. |
| M7 | امنیت و پشتیبان | پشتیبان رمزگذاری‌شده و بازیابی تولیدی وجود دارد؛ نصب تازه، اتصال مجدد و پذیرش بومی همچنان مانع انتشارند. |
| M8 | دفتر مالی | حساب، هزینه/درآمد، انتقال، اصلاح/ابطال و موجودی پایدار؛ بدون دوباره‌شماری انتقال. |
| M9 | تطبیق مالی | مسیر جزئی/کامل، اصلاح و قطع ارتباط وجود دارد؛ سیاست کامل اضافه‌پرداخت هنوز تصمیم جدا می‌خواهد. |
| M10 | صندوق بررسی و پیامک | واردسازیِ رضایت‌داده‌شده، پیش‌نویس و تأیید؛ هیچ منبع خامی مستقیماً دفتر را تغییر ندهد. |
| M11 | اتوماسیون محلی | قواعد و پیشنهاد آزمایشی؛ مسیر عمومی کامل و تأیید مستقل هنوز باز است. |
| M12 | پیش‌بینی و هوش مصنوعی اختیاری | مدل‌ها و قراردادها وجود دارند؛ آداپتور عمومی هوش مصنوعی روی دستگاه آماده نیست. |

## تصمیم‌های موجود

انتخاب شناسهٔ UUIDv7، SQLite/Drift، کتابخانه‌های رمزنگاری و آداپتور یادآور در کد و [ADRها](adr/) ثبت شده‌اند؛ عبارت قدیمی «هنوز انتخاب نشده» برای این موارد معتبر نیست. انتخاب تازهٔ مدیریت وضعیت، قالب داده، رمزنگاری پایگاه داده یا رفتار چندارزی نباید بی‌صدا انجام شود.

تکمیل یک مرحلهٔ زیرساختی به معنی آماده‌بودن همهٔ مسیرهای کاربر نیست. آزمون ناموفق یا اجرا‌نشدهٔ لازم، اجازهٔ اعلام آمادگی انتشار نمی‌دهد.
