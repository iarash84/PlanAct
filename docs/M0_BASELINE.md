# مبنای تاریخی مرحلهٔ <span dir="ltr">M0</span>

این سند زیرساخت اولیه را ثبت می‌کند، نه وضعیت جاری برنامه یا فهرست قابلیت آمادهٔ انتشار.

مبنای اولیه شامل ساختار لایه‌ای، <span dir="ltr">SQLite/Drift</span> و مسیر مهاجرت، <span dir="ltr">UUIDv7</span> مستقل از ردیف، ساعت <span dir="ltr">UTC</span> قابل تزریق، پول صحیح، خطای صریح، لاگ با پوشاندن فیلد حساس، الزامات فارسی/جلالی/راست‌به‌چپ و تست پایهٔ مخزن بود.

ارزیابی تاریخی شرایط <span dir="ltr">M0</span>: تحلیل بدون خطا، تست موفق و ساخت پایگاه حافظه‌ای با خواندن نسخهٔ طرحواره. فرمان تولید جدول:

<div dir="ltr">

```sh
dart run build_runner build
```

</div>

بررسی جاری و شرایط امضا را از [گردش توسعه](development-workflow.md) بخوانید. این مرحله شاهد قابلیت محصول یا ایمنی دستگاه نیست.

</div>
