# راهنمای شروع و خواندن مستندات

این مخزن پروژهٔ در حال توسعه است، نه بستهٔ پرامپت برای ساخت از صفر. پوشهٔ `prompts/` و فایل `docs/PROMPT_WORKFLOW.md` فعلاً وجود ندارند؛ اجرای پرامپت‌های P00 تا P38 راهنمای جاری نیست.

## مسیر پیشنهادی

1. [README](../README.md): قابلیت‌های قابل دسترسی و محدودیت‌های کاربر.
2. [PRD](product/PRD.md): نیازمندی محصول و معیار آمادگی؛ نیازمندی آینده را قابلیت موجود تلقی نکنید.
3. [قواعد معماری](ARCHITECTURE_AND_DOMAIN_RULES.md) و [ساختار کد](../lib/README.md).
4. [گردش توسعه](development-workflow.md)، [تست‌ها](../test/README.md) و [منابع فارسی](../lib/l10n/README.md).
5. [سیستم طراحی](DESIGN_SYSTEM.md) پیش از کار معنادار رابط.
6. سند `*_VERIFICATION.md` همان قابلیت برای مسیر واقعی، شواهد، محدودیت و مانع انتشار.
7. [تصمیم‌های معماری](adr/) برای تصمیم مصوب؛ [برنامهٔ توسعه](IMPLEMENTATION_PLAN.md) برای نقشهٔ مراحل.

## زبان و مخاطب

راهنمای کاربر و توسعه‌دهنده، نیازمندی، تصمیم معماری، گزارش پذیرش و یادداشت انتشار فارسی است. شناسهٔ کد، مسیر، فرمان، مقدار پروتکل و نام رسمی مجوز ترجمه نمی‌شود. خروجی خام تست زبان ابزار را حفظ می‌کند؛ [راهنمای شواهد](verification/evidence/README.md) را ببینید.

[AGENTS.md](../AGENTS.md) قرارداد اجرایی عامل کدنویسی و انگلیسی است. نمونهٔ پیام مستقیم به عامل:

```text
Read AGENTS.md and the relevant product and verification documents.
Inspect the current repository and preserve existing user changes.
Implement only the authorized scope and report observed evidence.
```

## مرجع رفتار و وضعیت

تصمیم مصوب جدیدتر بر PRD تقدم دارد؛ PRD رفتار محصول، AGENTS محدودیت اجرا و معماری جزئیات را مشخص می‌کنند. [مشخصات قدیمی](PRODUCT_SPEC.md) مرجع جاری نیست. نسخهٔ کد و طرحواره از `pubspec.yaml` و `AppDatabase.schemaVersion` خوانده می‌شود. تعداد تست قدیمی فقط شاهد همان اجراست.

## بازبینی مستندات؛ ۲۰۲۶-۱۰-۱۴

مبنای مقایسه کد ثبت‌شدهٔ `e18936f` است: نسخهٔ `0.1.16+9`، طرح ۱۸ و ۲۴ جدول، فهرست فارسی ۱٬۲۰۳ پیام، و ۳۳ نشان بانک کامل با حجم ۶۴۱٬۳۵۵ بایت. این شمارها مشاهدهٔ همین بازبینی‌اند؛ با تغییر کد دوباره بررسی شوند.

راهنمای کاربر/توسعه‌دهنده فارسی و قرارداد عامل انگلیسی باقی است. دستور، نام API/فایل، قالب پروتکل و شناسهٔ ماشینی اعتبارسنجی انتشار ترجمه نمی‌شوند. متن اصلی مجوز و مستندات بالادستیِ بسته‌های ثالث حفظ می‌شوند؛ راهنمای منشأ داده و دارایی متعلق به پروژه فارسی است.

مشخصات تکراری قدیمی به ارجاع تبدیل شد؛ پرامپت‌های ناموجود و شرح وضعیت منسوخ از راهنمای اجرا حذف شدند. شواهد تاریخی تاریخ‌دار، محدودیت داده/دستگاه و مسئولیت پذیرش حفظ شده‌اند. هر سند ارزیابی، شاهد همان قابلیت است و نتیجهٔ آزمون قدیمی به کل برنامه تعمیم داده نمی‌شود.

محدودهٔ این بازبینی فقط مستندات است؛ کد، تنظیم ساخت، طرح، وابستگی و داده تغییر نکرده‌اند. پیوندهای محلی، سازگاری شناسهٔ انتشار، اختلاف و حفظ فایل‌های خام بررسی شدند. آزمون/ساخت/دستگاه در این تغییر دوباره اجرا نشده؛ نتیجهٔ ۸۸۸ آزمون مربوط به [اصلاحات قبلی](SCHEDULE_ACTUAL_VERIFICATION.md) است. این بازبینی خودبازبینی مستندات است و پذیرش مستقل محصول یا رفع دروازهٔ بومی محسوب نمی‌شود.
