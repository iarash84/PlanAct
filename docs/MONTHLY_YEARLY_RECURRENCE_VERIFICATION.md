## Existing path and baseline findings

The wizard passes a draft to the root save callback, then CreateCommitmentPlan constructs a Gregorian day anchor and OccurrenceGenerator scans only start through start+90 days. Drift stores recurrence JSON in the existing text column and reads every cycle occurrence (no three-row limit). Today/Calendar refresh consumes those rows. Only creation generates occurrences. Thus approximately three monthly rows are materialization, not termination. Editing reconstructs recurrence rules and must preserve added semantics. Database schema is **18**, verified in the workspace (not 17).
