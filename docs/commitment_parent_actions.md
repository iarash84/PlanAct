# اقدام‌های تعهد والد و progress

- tap روی ردیف تعهد در امروز/تقویم یک bottom sheet کوچک با عنوان و وضعیت فعلی باز می‌کند.
- `انجام شد` فقط برای والد فعال معتبر است؛ `لغو تعهد` فقط برای فعال/متوقف؛ `بایگانی` برای هر والد غیر‌بایگانی. هیچ مسیر بازگشایی وجود ندارد.
- «جزئیات و ویرایش» ابتدا sheet را می‌بندد و سپس route مستقل جزئیات را باز می‌کند. route شامل وضعیت/نوع/تاریخ ایجاد و metadata قابل ویرایش است.
- عملیات lifecycle از use caseها عبور می‌کنند و رکورد فعلی repository را دوباره بارگذاری می‌کنند؛ UI روی snapshot قدیمی مستقیماً وضعیت را ذخیره نمی‌کند.
- progress فقط از occurrenceهای صریح و تکمیل‌شده نسبت به target ثابت محاسبه می‌شود. occurrenceهای cancelled/rescheduled کامل محسوب نمی‌شوند، horizon تولیدشده و ledger entitlement denominator نیستند، و target نامعلوم درصد ندارد.
- elapsed بودن بازهٔ تاریخ به‌تنهایی completion نیست و والد خودکار تکمیل نمی‌شود.
