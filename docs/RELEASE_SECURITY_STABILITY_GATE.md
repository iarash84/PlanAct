# ارزیابی تاریخی شرایط امنیت و پایداری انتشار

تاریخ شاهد: <span dir="ltr">۲۰۲۶-۰۹-۲۸</span>. این سند ممیزی وابستگی و تست همان مرحله است؛ وضعیت فعلی انتشار از [یادداشت نسخه](releases/0.2.0.md) خوانده می‌شود.

## تصمیم‌های همان مرحله

<span dir="ltr">`flutter pub outdated`</span> مبنای ممیزی بود. اعلان از ۱۹٫۵٫۰ به <span dir="ltr">`^22.3.1`</span> و منطقهٔ زمانی از ۰٫۱۰٫۱ به <span dir="ltr">`^0.11.1`</span> رفت؛ <span dir="ltr">API</span>های نام‌دار آداپتور به‌روزرسانی شدند. بستهٔ <span dir="ltr">`sqlite3_flutter_libs`</span> با قید <span dir="ltr">`^0.5.29`</span> به خط <span dir="ltr">`0.6.0+eol`</span> ارتقا نیافت؛ تغییر پشتهٔ <span dir="ltr">SQLite</span> به تصمیم سازگاری جدا نیاز داشت. <span dir="ltr">Drift</span>/مولد بدون ارتقای مستقل باقی ماندند. مهاجرت مخرب یا بازآرایی گسترده نبود. نسخهٔ حل‌شدهٔ امروز باید از فایل قفل خوانده شود، نه جدول تاریخی.
