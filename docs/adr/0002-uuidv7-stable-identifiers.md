# تصمیم معماری ۰۰۰۲: شناسهٔ پایدار <span dir="ltr">UUIDv7</span>

وضعیت: پذیرفته‌شده؛ تاریخ: <span dir="ltr">۲۰۲۶-۰۹-۲۰</span>.

هویت موجودیت دامنه باید مستقل از شناسهٔ ردیف <span dir="ltr">SQLite</span> باشد. انتخاب ثبت‌شده <span dir="ltr">UUIDv7</span> رشته‌ای است: زمان <span dir="ltr">Unix</span> بر حسب میلی‌ثانیهٔ <span dir="ltr">UTC</span>، بیت نسخه/گونه، توالی در هر میلی‌ثانیه و بایت تصادفی امن. وابستگی جداگانهٔ تولید شناسه اضافه نشده است. متن معتبر با حروف بزرگ یا کوچک پذیرفته و به حروف کوچک نرمال می‌شود.

شناسه تقریباً مرتب زمانی است، اما جای زمان صریح دامنه را نمی‌گیرد. شناسهٔ ردیف <span dir="ltr">SQLite</span> هویت دامنه نیست. جایگزینی مولد با بستهٔ دیگر در آینده باید رشته‌های ذخیره‌شده را سازگار نگه دارد.
