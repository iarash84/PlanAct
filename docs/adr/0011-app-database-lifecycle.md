# تصمیم ۰۰۱۱: مالکیت و چرخهٔ عمر پایگاه داده

- وضعیت: پذیرفته؛ مالک تولید و هماهنگی پشتیبان پیاده‌سازی شده‌اند
- تاریخ تصمیم اولیه: <span dir="ltr">۲۰۲۶-۰۹-۲۸</span>

## تصمیم و اجرای فعلی

ریشهٔ ساخت برنامه یک مالک <span dir="ltr">`AppDatabase`</span> دارد؛ مخزن‌ها فقط مرجع می‌گیرند و حق بستن آن را ندارند. پایگاه پیش از ساخت مخزن‌ها آماده و با <span dir="ltr">`await database.close()`</span> بسته می‌شود. منابع وابسته، اشتراک‌ها و آداپتورهای فعال باید با بستن/جایگزینی هماهنگ باشند.

<span dir="ltr">`AppDatabaseLifecycle`</span> و <span dir="ltr">`BackupApplicationScope`</span> این مالکیت و بازاتصال مخزن‌های تولید هنگام بازگردانی را مدیریت می‌کنند. قرارداد هماهنگی فرمان‌ها و منابع باید با شواهد مسیر واقعی پشتیبان بررسی شود؛ وجود مالک به‌تنهایی ایمنی همهٔ هم‌زمانی‌ها نیست.

<span dir="ltr">`AppDatabase.forTesting`</span> فقط برای آزمون/دادهٔ آزمایشی است؛ مالکیت و بستن در پایان آزمون صریح‌اند. راه‌اندازی سرد باید همان فایل <span dir="ltr">SQLite</span> را باز کند و حالت پایدار را بازسازی کند. مهاجرت، بستن/بازکردن و بازگردانی آزمون دارند؛ [شواهد تولید پشتیبان](../BACKUP_VERIFICATION.md) حدود پذیرش بومی را مشخص می‌کند.

این تصمیم معماری مالکیت است و به‌تنهایی قابلیت آمادهٔ کاربر یا پذیرش مستقل انتشار محسوب نمی‌شود.
