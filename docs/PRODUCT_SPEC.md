# مشخصات قدیمی محصول — ارجاع به مرجع جاری

مشخصات مورخ ۲۰۲۶-۰۹-۲۶ با [PRD جاری](product/PRD.md) جایگزین شده است. نسخهٔ قدیمی مالی را متکی به حافظه، مبلغ مورد انتظار را ناموجود و امروز، صندوق بررسی و گزارش‌ها را فاقد مسیر کاربر معرفی می‌کرد؛ این ادعاها با کد فعلی سازگار نیستند.

جدول و متن تکراریِ مشخصات منسوخ حذف شده‌اند تا دو قرارداد متعارض باقی نماند. متن اصلی در تاریخچهٔ Git قابل مراجعه است. این مسیر برای حفظ پیوندهای قبلی نگه داشته شده است.

برای وضعیت واقعی، سند پذیرش همان قابلیت و تعریف آمادگی در PRD را بخوانید؛ وجود مدل یا رابط به معنی آمادگی انتشار نیست.
