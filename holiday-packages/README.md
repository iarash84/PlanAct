# بسته‌های مستقل تعطیلات

این پوشه مقصد فایل‌های آمادهٔ تحویل است. دادهٔ نهایی بررسی‌شده در [فایل‌های سالانه](../third_party/iranian_holidays/reviewed/) قرار دارد؛ همان فایل‌ها مبنای دادهٔ همراه برنامه و ورودی امضای بسته‌اند.

## فایل‌های آمادهٔ امضا۱۴۰۷–۱۴۱۰

مطابق درخواست کاربر و اعلام نداشتن کلید ناشر، این چهار فایل مانند داده‌های قبلی به‌صورت payload بدون امضا تحویل شده‌اند. منبع، تقویم نمایش‌داده‌شدهٔ time.ir است؛ همهٔ۴۸ماه و۱۴۶۱روز بررسی شدند، اما PDF رسمی مستقلاً تأیید نشده است. تاریخ قمری محلی تخمین زده نشده است.

جمعه مستقل است و در شمار تاریخ‌های تعطیل این جدول نیامده است؛ دلایل هم‌زمان حفظ شده‌اند. در۱۴۰۸ روز۳۰اسفند، مطابق نشان منبع با عنوان «آخرین روز سال»، یک رکورد صریح همان سال است؛ هیچ قاعدهٔ تکرار یا دادهٔ تاریخی عوض نشده است.

این فایل‌ها مستقیماً واردشدنی نیستند. برای ورود از «بیشتر»، باید با کلید ناشر مورد اعتماد امضا شوند؛ کلید واقعی در اختیار این کار نبود و امضای آزمون، بستهٔ انتشار نیست. فایل‌ها به catalog همراه اضافه نشده‌اند و نیازی به تغییر/ساخت برنامه برای آماده‌سازی آن‌ها نبود. مسیر امضای زیر برای هر کدام با تغییر نام فایل قابل استفاده است.

برای نمونهٔ۱۴۰۶، با کلید خصوصی موجود ناشر در مسیری محافظت‌شده خارج مخزن:

```sh
dart run tool/holiday_package.dart validate third_party/iranian_holidays/reviewed/iran-1406-r1.json
dart run tool/holiday_package.dart sign PRIVATE_SEED third_party/iranian_holidays/reviewed/iran-1406-r1.json holiday-packages/iran-1406-r1.planact-holidays.json
dart run tool/holiday_package.dart verify holiday-packages/iran-1406-r1.planact-holidays.json
```

هر سال با همان ناشر امضا می‌شود. فایل payload خوانا مستقیماً واردشدنی نیست؛ فایل خروجی امضاشده از «بیشتر ← دادهٔ تعطیلات ← ورود بسته از فایل» وارد می‌شود. ناشر اول با اثرانگشت از کانال مستقل معتبر تأیید می‌شود. کلید خصوصی را اینجا نگذارید؛ بستهٔ اصلی خارج پشتیبان شخصی است و باید جدا نگهداری شود.

فایل امضاشده با کلید ناشر واقعی تولید/منتشر نشده است. آزمون‌های مخزن برای بررسی چهار payload بالا از امضاکنندهٔ مصنوعی استفاده می‌کنند؛ خروجی امضاشدهٔ آزمون فایل انتشار نیست. سایر fixtureهای سال آینده مصنوعی‌اند و با این چهار نگاشت منبع یکی نیستند. برای سال‌های بعد از۱۴۱۰ ابتدا بررسی واقعی منبع لازم است.
