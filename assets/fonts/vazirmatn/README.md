# قلم فارسی بسته‌بندی‌شده

فایل‌های بدون تغییر Vazirmatn از انتشار رسمی [v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003/fonts/ttf) دریافت شده‌اند. ناشر: The Vazirmatn Project Authors. توزیع و جاسازی طبق [مجوز SIL OFL 1.1](OFL.txt) مجاز است؛ متن حق نشر و مجوز همراه برنامه و در مجوزهای صفحهٔ درباره عرضه می‌شود. این دارایی بستهٔ نرم‌افزاری جدید یا وابستگی شبکه در زمان اجرا نیست.

وزن‌های عادی ۴۰۰، متوسط ۵۰۰، نیمه‌ضخیم ۶۰۰ و ضخیم ۷۰۰ در [پیکربندی برنامه](../../../pubspec.yaml) ثبت شده‌اند. فایل‌ها زیرمجموعه‌سازی، تبدیل یا بازنام‌گذاری خانواده نشده‌اند. مجموع حجم چهار قلم حدود ۴۸۰ کیبی‌بایت است. مرجع مرکزی [تایپوگرافی](../../../lib/app/theme/planact_typography.dart:4) است؛ قلم محلی در صفحه‌ها تعریف نشود.
