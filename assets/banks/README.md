# تصاویر بانک‌های ایران

منبع، پوشهٔ محلی <span dir="ltr">`D:/repos/IranianBankLogos/resources/images`</span> ارسالی کاربر در <span dir="ltr">۲۰۲۶-۱۰-۱۳</span> است. برش‌های قبلی جایگزین شدند؛ حدس هویت و برش ثابت، برخی نشان‌ها و نوشتهٔ پایین را نادرست یا ناقص می‌کرد.

۳۳ <span dir="ltr">PNG</span> رنگی کامل ۳۰۰×۳۰۰، با فشرده‌سازی بدون اتلاف و حجم مجموع ۶۴۱٬۳۵۵ بایت همراه برنامه‌اند. تمام پیکسل‌های <span dir="ltr">RGB</span>، نوشتهٔ پایین، تناسب و زمینهٔ سفید حفظ شده؛ برش یا تغییر اندازه انجام نشده است. زمینهٔ سفید خوانایی نشان در تم روشن و تیره را حفظ می‌کند.

<span dir="ltr">`manifest.json`</span> نام فایل منبع و <span dir="ltr">SHA-256</span> خروجی را ثبت می‌کند. نگاشت پس از بازبینی گالری کامل نام‌دار انجام شد: رفاه=<span dir="ltr">`rb`</span>، کارآفرین=<span dir="ltr">`kar`</span>، پست‌بانک=<span dir="ltr">`post`</span>، حکمت=<span dir="ltr">`hi`</span>، توسعهٔ صادرات=<span dir="ltr">`edbi`</span>، خاورمیانه=<span dir="ltr">`me`</span>، صنعت‌ومعدن=<span dir="ltr">`bim`</span>، ایران‌ونزوئلا=<span dir="ltr">`ivbb`</span>، رسالت=<span dir="ltr">`resalat`</span> و ملل=<span dir="ltr">`melal`</span>. <span dir="ltr">`rb2`</span> نشان جایگزین قدیمی رفاه است؛ حساب از <span dir="ltr">`rb`</span> استفاده می‌کند. فایل منبع مهر اقتصاد موجود نیست. ۲۰ فایل به کدهای انتخابی بانک نگاشت و بقیه فقط دارایی‌اند.

هنگام ورود، هر پیکسل خروجی با فایل متناظر منبع برابر بود؛ آزمون‌ها نگاشت بازبینی‌شده، هش خروجی و رمزگشایی تصویر را محافظت می‌کنند. انتخاب بانک، کد ذخیره‌شده، دادهٔ مالی و وابستگی عوض نشده‌اند. این برابری، مجوز حقوقی یا پذیرش مستقل ظاهر دستگاه نیست؛ حدود پذیرش در [ارزیابی حساب و برند](../../docs/ACCOUNT_BRAND_VERIFICATION.md) ثبت شده‌اند.
